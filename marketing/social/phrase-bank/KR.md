# 韓國（KR）用語庫

建立：2026-10-26（第一版，來源為 X 近 7 天公開貼文；未經母語者審閱）。
說明：韓國主流是 Instagram／Naver 部落格／Threads，X 上以追星、加密貨幣帳號為主；本版先收 X 可用樣本，下輪補 Threads／Naver。

## 1.「好久沒／上次是什麼時候」句型
- 「몇 년 만에」「오랜만에」：「대학 시절 친구에게서 몇 년 만에 전화가 왔다.」（44 讚、2 回覆）https://x.com/sohn_ji/status/2113658432427593913
  - 結構：一句事件→一句感想→短短幾行敘事→祝福收尾（응원한다）。真誠、不賣東西。
- 「마지막으로 …했던 날이 언제였는지조차 가물가물할 만큼」：「20여 년 만에 다시 써보는 손편지. 💌 마지막으로 누군가에게 손편지를 썼던 날이 언제였는지조차 가물가물할 만큼…」https://x.com/yeonwoo78y/status/2113560970320842944 → 幾乎就是 Been Ages 的核心情緒，可借句型「마지막으로 ○○한 게 언제였더라」。
- 「몇 십 년 만에 감자칩을 먹는 중ㅋㅋㅋ」https://x.com/ENGENE11_30/status/2113878999604867223 、「어젯밤 간만에 (정확히는 몇 년 만에) 8시간 넘게 잤는데」https://x.com/_ol_v13/status/2113798295617454218 → 小事＋「ㅋㅋㅋ」自嘲。
- 「나 진짜 왕 홈플러스 …는 몇 년 만에 간다」https://x.com/shurenim/status/2113600447152062810

## 2. app／記錄 app 相關
- 高互動開發者心得：「앱인토스로 미니앱 100개 넘게 만들어보고 깨달은 꿀팁 … 습관 기록, 일기, 나만 좋아하는 취미 앱... 저도 그랬어요」（135 讚、193 收藏、20 回覆、約 1.4 萬曝光）https://x.com/Pixy7Crypto/status/2113865825882939521
  - 鉤子：「做了 100 個之後學到的꿀팁」＋編號清單；收藏高。內容認為習慣記錄類 app 很多人做、不易起量 → 提醒：韓國市場「記錄 app」是擁擠類別，訴求要更具體（「上次是什麼時候」而不是「習慣養成」）。
- 開發日誌提問收尾：「기록 앱 만드는 중 … '예: 화분 물 주기' 같은 예시 넣었더니 바로 구분됨 / 다들 위젯 고를 때 뭐 보고 고름?」（2 讚、1 回覆）https://x.com/doyun_dev_kor/status/2113546268253594081 → 結尾用「다들 ~ 뭐 보고 고름?」半語提問引互動。
- 推薦清單格式：「평범한 하루도 귀엽게 남기고 싶다면 🎀 일상 기록 앱 4가지」https://x.com/momo_dailylog/status/2113546022479855983 、「여행 기록 앱 4개, 뭐가 다른지 정리함」https://x.com/xxlyul/status/2112514180825923770 （互動低，但這是韓國常見的「N 選」格式，較適合 IG/Threads 輪播）。

## 3. 語氣
- X 上多用半語（반말）＋「ㅋㅋㅋ」「ㅁㅊ」；品牌帳號用 해요體較安全，回覆可略口語但不要 ㅁㅊ 等粗口。
- 「~했어요」「~더라고요」經驗分享口吻自然。

## 4. AI 腔黑名單（韓文）
- 品牌口號式短句＋連結：「오늘도, 한 번 더. 작은 기록을 돌아보는 습관.」（Kilory，0 讚、15 曝光）https://x.com/joinKilory/status/2113212744342417815 → 詩意標語無人互動。
- 每日同模板貼文（例 https://x.com/kwondoyun80/status/2114283417764573398 為固定格式，雖非 app 類，示範模板感）。
- 避免：「~해 보세요!」連發、「최고의」「혁신적인」誇大、條列＋emoji 串、開頭丟連結。
