# 工作流程

## 每個 app PR（安全審查通過後）
1. 等碼農通知（漏洞大師已通過）。
2. 實際跑一次 `bots/user-tester/test-flows.md` 裡的流程。
3. 回報通過或未通過（給碼農／黑嘛嘛）。合併與 EAS 打包都要等我通過。
4. 備份 repo 的純文件 PR 不用測。

## 使用研究
1. 先不看 app，從真實生活出發，列出 10–15 個「多久沒做某件事」的使用流程：什麼時候會想到、想記什麼、想知道什麼、多久看一次。
2. 在 box 上用最新的 main，以 iPhone 尺寸（390×844）的 Expo web 執行 app3/mobile，並用 Playwright 逐一操作每個流程。記錄步驟數、卡住的地方和使用感受，並附上截圖。
3. web 上無法測的功能（widget、通知、行事曆、內購）改看程式碼推測，並標明「推測」。
4. 依影響大小排列優化建議，每一項都對應到相關的流程和證據；特別留意「什麼會讓人每天想打開這個 app」。
5. 把前 5 大問題和建議簡短回報給黑嘛嘛。不 build、不 push。
