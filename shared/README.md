# Shared Workspace (Long-term)

Durable handoff and knowledge area between SuperGrok and Grok Bots.

- Prefer this repo for content that should survive computer wipes.
- Use `tinytoolshedhq/app/shared/` for short-term execution tasks.

## Structure
- `drafts/` — longer-lived drafts or archives
- `strategy/` — refined strategy documents
- `notes/` — SuperGrok notes and summaries

Never commit secrets, tokens, or large binaries.
