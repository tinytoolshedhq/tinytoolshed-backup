## F16 原因分析（Chun 回報按不了）
- 檔案：`app3/mobile/src/components/AiEditSheet.js`
- 舊版（f737573 以前）第 31 行是 `now = Date.now()` 預設參數，每次畫面重畫都會產生新的 `now`；第 38–44 行的 `useEffect` 依賴 `[visible, item, now]`，所以點一下選項 → 重畫 → effect 又跑 → 把「上次做是」「提醒」重設回原本的值。看起來就像按不了（不是被蓋住或 disabled）。
- a88a9da（#35）改成 `now` 不給預設、用 `useRef` 存時間，web 上實測已修好。
- 如果 Chun 手機上還是按不了，很可能裝的是 #35 之前的版本（需要新 build，我沒有 build）。
- 剩下的小風險：`AiChatScreen.js` 第 381 行 `item={msgs.find(...)?.item}`，如果 msgs 在 sheet 開著時更新，effect 一樣會重設選項。
