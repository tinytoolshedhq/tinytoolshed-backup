# 測試發現

## 第 1 輪：2026-10-14，main @ 3690694

### 前 5 大問題
1. 新增項目只能把日期設成今天；補記只能選今天、昨天或 3 天前，所以每個新項目都從 0 開始。
2. 新增時不能設提醒，要先建立項目再進詳情頁設定，整個流程要 8 步。
3. 免費版只能記 3 件，新增第 4 件就跳出付費頁。
4. 新增後預設成「剛做過」，首頁全是 0 和打勾，看不出哪件比較急。
5. 沒有讓人每天想打開的理由：首頁沒有「今天該做的」，完成後也沒有回饋。

### 前 5 大建議
1. 新增和補記都能選任意日期，並提供快選：1 週前、1 個月前、不記得。
2. 在新增頁直接選提醒週期，並依項目名稱自動建議。
3. 把免費上限放寬到 7–10 件，或不設上限，改成賣 widget 和分享樣式。
4. 首頁頂端加入「今天該做的」，可以一鍵完成；全部做完時吉祥物會變開心。
5. 新增時預設成「還沒記錄」；完成後給一行回饋；首頁空白時提供常見範本。

### 其他問題
- 排序鈕沒有顯示目前用的是哪一種排序。
- 備註只能寫在項目上，不能每筆紀錄各寫一則。
