## 問題（依嚴重度）
1. **中（網頁／開發）恢復購買卡在「等待中…」**：網頁上 react-native-web 的 `Alert.alert` 什麼都不做，模擬恢復的確認框不會出現，Promise 永遠不會結束。app3 有 `webAlert` 補這個，app5 沒有。真機用 StoreKit 路線推測不會卡；但開發版的模擬路線也靠 Alert，真機上原生 Alert 有效，推測正常。建議加 webAlert，或給 `restoreProUnlock` 加逾時
2. **中（安全）**：每個動作的注意事項，還有懷孕／手術後／受傷要先諮詢的提醒，UI 都沒顯示
3. 小：只有中文；英文系統也是中文
4. 小：躺著＋5 分只有 3 個動作輪流（腳踝勾放、手指開合各重複 4～5 次），有提示「本次會重複部分動作」，但阿姨會覺得很單調
5. 小：播放頁動作名稱出現兩次；動畫只有佔位符號「│○│」（media_status=not_created）
6. 小：商品 ID 暫定；付費頁價格「無法取得」（網頁上正常）
