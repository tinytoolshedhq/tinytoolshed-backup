# Been Ages 固定測試腳本（胖嘟嘟阿姨）

（2026-10-20 依 PR #37 更新預期結果）

每次測試都照這份跑。環境：Expo web，iPhone 尺寸 390×844，語系 zh-TW，資料從空白開始（清 localStorage）。
結果分四種：通過／失敗／卡住／推測（web 測不到：widget、通知、行事曆、內購）。
免費版上限：10 個項目、每項 10 筆紀錄。

角色：
- A 胖嘟嘟阿姨：55 歲家庭主婦、養貓、不懂 3C、沒耐心看說明
- B 上班族：忙、只想快點記完
- C 學生：常忘記、用手機很快
- D 新手爸媽：單手操作、睡眠不足
- E 養狗的人：寵物用品要定期換
