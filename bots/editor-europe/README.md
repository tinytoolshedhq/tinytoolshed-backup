## 規則摘要（2026-10-20）
- App Store 上架前，不發文也不回覆。
- 上架後每則貼文和回覆都要做到三件事：
  - 說明目前還沒有 Android 版
  - 附 Chun 提供的 1 支影片和 1 張照片，沒有素材就不發
  - 附 App Store 連結
- 上架後，回覆別人的貼文不用等核准，但不能大量回覆或自動回覆；品牌自己的新貼文仍要 Chun 核准。
- 英國只做 ASO，不發文、不回覆。德國和法國以 ASO 和短影音為主。
- 定價：一次買斷，英國 £2.99、德國和法國 €2.99（和美國 $2.99 同一級），沒有上市優惠，不開家人共享，文案不寫 unlock、freischalten、débloquer。
- 免費版：10 個項目，每項 10 筆紀錄。
